本番UIから物理的に隔離した静的シェル。旧 `index.html` / `main.js` / `data.js` / `style.css`
には接続せず、旧CSSを import せず、旧DOM・旧セレクタも再利用しない。

Visual North Star は正式カンプ `FORMAL_COMPS/DAY/*.png` ・ `FORMAL_COMPS/NIGHT/*.png` のみ。
（03・04 のみ 2026-08-09 承認の新 concept board。旧 03・04 カンプは失効扱い。）
現行サイト・旧UI・旧VR1 の見た目は視覚の参照にしていない。

## プロダクトコア Ver.2（2026-08-09 決定）

みんなの感情書店は、感情を入口に、外の世界と自分の内側を往復するデジタル書店。
価値は**順序ではなく3つ**。

| | |
|---|---|
| **出会う** | 感情から、ことば・本・映画・音楽・今の言葉へ |
| **残す** | 自分の中に残ったものを、自分の言葉で書き、一冊にする |
| **再会する** | 自分の本棚から、過去の一冊や同じ感情の世界へ戻る |

**「まず書く → 本にする」は唯一の正規ルートではない。**
UI 上でこの3つを手順・段階・達成として並べない（番号・矢印・ステップ表現を付けない）。

- 06・07 は**再会する**を担う画面。
- 06 の本棚の価値は「何冊持っているか」ではなく、過去の一冊を取り出して再会できること。
  Visual Asset／Adapter 工程でも**冊数・空き枠・蔵書数を達成指標のように強調しない**。
- 08 は「本がない＝書かなければならない」という圧力を作らない。

## 昼夜の切り替え

`:root[data-v2-theme="day" | "night"]` のみで切り替える。DAY/NIGHT は同一DOM。
既存本番の `body.night` / `data-daypart` / `applyNightModeIfNeeded()` / `currentDaypart()`
には触れていない（保護領域）。

各画面（`screens/01-cover.html` / `screens/02-menu.html`）には Visual QA 専用の最小インラインJSが1本だけ入っている。
URLパラメータ `theme=day|night` を読み `data-v2-theme` を差し替えるだけで、
保存しない／localStorage を使わない／GA4 を呼ばない／外部通信しない／時刻判定しない。
**Phase 3 の本番Adapter接続時には、この処理を本番ロジックへ持ち込まない。**

## Phase 3 Step 3D — 書く → 本にする → 自分の本棚 → 一冊を読む（2026-08-10 CEO決裁）

05「書く」を既存の保存・製本ロジックへ接続し、中核経路を完成させた。
同時に 07 の「押せそうなのに動かない」操作を整理した。

**保存・製本・下書き・検証・GA4 のロジックは V2 側に一切持たない（再実装しない）。**

### 既存の書く／製本の呼び出し経路（監査結果）

| 既存要素 | 役割 |
|---|---|
| `#storyInput` | 本文。input listener が下書き保存（500ms デバウンス）・文字数・題名提案を担う |
| `#titleInput` | 題名（任意）。空欄時の fallback「まだ、題名のない本」も既存側 |
| `#submitStory` の onclick | **製本の唯一の入口**。検証 → `runBinding` → `saveJSON` → 読み戻し確認 → `renderShelf` → GA4 |
| `#deskMsg` / `#storyCount` | 既存の結果表示・文字数表示 |
| `#unfiledShelfSkip` | 製本成功後「今は棚を決めず、本棚へ」。既存の離脱経路 |
| `handleGenuineStartWritingInput` | `Event.isTrusted` で利用者本人の入力を判定し `start_writing` を1回だけ送る |

初回製本の category は既存実装が**常に `UNFILED_CATEGORY_ID`** を使う
（`#categorySelect` の値は初回保存に使わない）。V2 もこれを変えない。

### form-adapter がすること

1. V2 の本文欄・題名欄の値を既存 `#storyInput` / `#titleInput` へ写し、合成 `input` イベントで
   既存の下書き保存・文字数・題名提案を動かす
2. 「本にする」で既存 `#submitStory` を押す
3. 既存 `#deskMsg` / `#storyCount` / `#submitStory.disabled` を V2 へ写す
4. 成功したら既存 `#unfiledShelfSkip` を通り、V2 は 06 を表示する

`start_writing` は既存関数 `handleGenuineStartWritingInput` **そのもの**を V2 本文欄にも
listener として付けて発火させる（利用者の実入力だけが `isTrusted=true`）。
V2 から既存欄へ写す合成イベントでは発火しない＝既存の判定条件をそのまま維持する。

### 検証・GA4・保存の同一性（実測）

本番 `index.html` 上で「既存欄へ直接入力して既存ボタンを押す経路」と
「V2 Adapter 経路」を同一ケースで比較した。

| 比較項目 | 結果 |
|---|---|
| GA4 イベント列 | `["start_writing","create_book_success","view_shelf"]` で**完全一致** |
| `DataRepository` 呼び出し列 | `set:draft → set:library → get:library → get:shiori → remove:draft → get:milestones → set:milestones` で**完全一致** |

**V2 由来の新イベント 0 / 二重発火 0 / 新 storage key 0 / 製本経路の外部通信 0。**

入力 → 既存デバウンス保存、`restoreDraftIfAny()` → V2 へ引き取り、

## Pre-Mount Visual Accessibility Hotfix — モバイル文字サイズ（2026-08-10 CEO決裁）

Phase 3 Final で実測した「狭い画面で文字まで比例縮小し読めなくなる」問題だけを限定修正した。
**新機能・IA変更・画面再設計・storage / GA4 / network / privacy / data model / protected contracts の変更はゼロ。**

### 方式：レイアウトとタイポグラフィのスケールを分離する

`--v2-px`（レイアウト寸法）は**一切変更していない**。
`base.css` に**タイポグラフィ専用スケール**を新設し、font-size / line-height だけをこれに切り替えた。

```css
.v2-stage {
  --v2-px:  calc(100cqw / 853);        /* レイアウト：従来どおりカンプ幅へ完全比例 */
  --v2-tpx: max(0.86px, var(--v2-px)); /* タイポグラフィ：狭い画面でだけ下限が効く */
}
```

- `max()` なので **カンプ原寸（`--v2-px` ≥ 0.86）では 1px 相当のまま**。原寸の見え方は変わらない
- メディアクエリを使っていないため、**幅を変えても見え方が不連続に飛ばない**
- `--v2-tpx` は font-size / line-height 以外には使わない（余白・枠・配置は従来どおり）
- 各画面の `--v2-px` 定義（1024 / 1122 / 853）は無変更。下限は画面をまたいで文字サイズを揃える

切り替えた宣言：**112**（font-size 80 / line-height 32、10ファイル）。
`--v2-px` そのものを下限固定して画面全体を一括拡大する方法は採用していない。

### 局所修正（文字下限で崩れた箇所だけ）

| 画面 | 症状 | 修正 |
|---|---|---|
| 05 | ボタン内の補助文が `white-space: nowrap` で横へはみ出す | 折り返しを許可（`max-width:100%` / `text-align:center` / 左右 padding）。ボタンと自動保存文は `height` → `min-height` |
| 08 | 見出し・副文が `nowrap` で横へはみ出す | 折り返しを許可。`left:50%` + `translateX(-50%)` は利用可能幅が半分になり原寸でも改行してしまうため、**左右いっぱいの帯 + `text-align:center`** へ変更（視覚的な中心は従来と同じ） |

### 結果

|---|---|---|---|---|
| 320px | 4.69px | **12.90px** | **0**（before 97） | **0**（before 99） |
| 390px | 5.71px | **12.90px** | **0**（before 83） | **0**（before 97） |
| 512px | 7.50px | **12.90px** | **0**（before 47） | **0**（before 79） |
| 1440px | 21.09px | 21.09px | 0 | 0 |

**カンプ原寸（01=853 / 02〜07=1024 / 08=1122）× DAY/NIGHT の16画面で pixel diff 0** —
Visual North Star は一切崩していない。
