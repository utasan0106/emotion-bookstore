本番UIから物理的に隔離した静的シェル。旧 `index.html` / `main.js` / `data.js` / `style.css`
には接続せず、旧CSSを import せず、旧DOM・旧セレクタも再利用しない。

Visual North Star は正式カンプ `FORMAL_COMPS/DAY/*.png` ・ `FORMAL_COMPS/NIGHT/*.png` のみ。
（03・04 のみ 2026-08-09 承認の新 concept board。旧 03・04 カンプは失効扱い。）
現行サイト・旧UI・旧VR1 の見た目は視覚の参照にしていない。

## プロダクトコア Ver.2（2026-08-09 決定）

みんなの感情書店は、感情を入口に、外の世界と自分の内側を往復するデジタル書店。
価値は**順序ではなく3つ**。

| | |
|---|---|
| **出会う** | 感情から、ことば・本・映画・音楽・今の言葉へ |
| **残す** | 自分の中に残ったものを、自分の言葉で書き、一冊にする |
| **再会する** | 自分の本棚から、過去の一冊や同じ感情の世界へ戻る |

**「まず書く → 本にする」は唯一の正規ルートではない。**
UI 上でこの3つを手順・段階・達成として並べない（番号・矢印・ステップ表現を付けない）。

- 06・07 は**再会する**を担う画面。
- 06 の本棚の価値は「何冊持っているか」ではなく、過去の一冊を取り出して再会できること。
  Visual Asset／Adapter 工程でも**冊数・空き枠・蔵書数を達成指標のように強調しない**。
- 08 は「本がない＝書かなければならない」という圧力を作らない。

## 昼夜の切り替え

`:root[data-v2-theme="day" | "night"]` のみで切り替える。DAY/NIGHT は同一DOM。
既存本番の `body.night` / `data-daypart` / `applyNightModeIfNeeded()` / `currentDaypart()`
には触れていない（保護領域）。

各画面（`screens/01-cover.html` / `screens/02-menu.html`）には Visual QA 専用の最小インラインJSが1本だけ入っている。
URLパラメータ `theme=day|night` を読み `data-v2-theme` を差し替えるだけで、
保存しない／localStorage を使わない／GA4 を呼ばない／外部通信しない／時刻判定しない。
**Phase 3 の本番Adapter接続時には、この処理を本番ロジックへ持ち込まない。**

### 06〜08 のデータ方針

利用者の実データにあたるもの（本の題名・日付・冊数・本文・章題・文字数・
しおり件数・ページ位置）は**文字を置かず、占有位置と余白だけを中立プレースホルダー**で作る。
UI 側の文言（見出し・ラベル・注記・操作名）はそのまま置く。
保存データを読まず、fake production data も作らない。

- 06：背表紙6枠＋追加枠1、日付帯、最近開いた本2行、下書き1行 — すべて枠のみ
- 07：書影・題名・製本日・説明・本文・章題・ページ位置・各件数 — すべて枠のみ。
  ラベル（しおり／メモ・線を引いた箇所／目次／共有（URLをコピー）／本にした日／
  文字数／保存先／公開設定／編集する）は UI 文言としてそのまま置く
- 08：空状態のため全文言が UI 側のもの。streak・達成率・空き枠・製本数は置かない

### 06〜08 の照明

- 06：棚板の間接照明。吊り下げライトは置かない
- 07：紙面そのものが読める静かな読書光。器具は主張させない
- 08：本棚周辺のごく弱い環境光。カンプ上部の吊り下げ灯は主役として再現しない

08 の「戻る」は DAY カンプに無く NIGHT カンプにあるが、DAY/NIGHT 同一DOM の決定に従い両方に置いている。


## 07 の共有機能について（未確定機能）

07 の `共有（URLをコピー）` と `このページを共有` は、**現時点で正式機能として承認されていない**。
私的な本文ページそのものを共有できると誤認させるためである。

- Phase 1 では操作枠自体は残すが、**静的・非活性**であり本文共有機能は実装していない
- 本文共有機能を新規実装しない
- Phase 3 Adapter 接続時に、現行実装の実際の共有範囲・privacy 仕様と照合して正式判断する

## 08 の Core Ver.2 整合（2026-08-09）

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| 補助文 | 最初の一篇を書いてみませんか？ | ここから、気になる棚を覗くことも、今残っていることを書き留めることもできます。 |
| 3項目のラベル | はじめ方 | （削除。手順の枠組みを示すため。罫のみ残す） |
| 3項目 | 書きはじめる／下書きは自動で保存／あなたの本になる | 出会う／残す／再会する |
| 次の行動 | 単独 Primary CTA「編纂室で書きはじめる」＋ text link | 同格の2ボタン「感情の棚を見る」「ことばを残す」 |

「まだ、あなたの本は棚に並んでいません。」は維持している。

3項目は**操作手順ではなくサービスの3つの過ごし方**なので、等幅・等間隔・同一書式で並列に置き、
番号・矢印・ステップ表現を付けていない（実測で幅・y・書式がすべて一致することを確認済み）。
2つの入口も同寸・同書式・同色で、どちらが正しい入口かという視覚的な優劣を作っていない。
Phase 1 ではどちらも非活性で、route も event も持たない。

安心情報は「この端末にのみ保存されています」の方向を維持している。
将来の正式文言では保存限界・別端末・ブラウザ削除等も説明するため、
現時点で「絶対に消えない」「完全に安全」等の表現は追加していない。
