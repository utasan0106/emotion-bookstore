# 廃止記録：日記サービス（V2）

2026-08-29、CEO 判断でドメイン直下（`https://emotion-bookstore.vercel.app/`）
から廃止し、代わりに文化案内（旧 `v3-prototype/release-01/` → `machi/`）を
そこへ昇格させた。

このサービス自体は 2026-08-24 に「V3 Production GO」として正式リリース
済みで、baseline は `eca334f9671bee07833892b2476aac118f8ed018` に凍結されて
いる。バグや不具合があっての廃止ではない。

## いま起きていること

- ファイル一式をこのディレクトリへ移した（`git mv`。削除ではない）
- `.vercelignore` の `archive/` 指定により、配信はされない
- 直リンクを持っている利用者がいた場合、その URL は 404 になる
- 利用者が端末に保存していた本文・写真・本棚データ（IndexedDB / LocalStorage）
  は、この操作の影響を受けない。ブラウザ側のストレージなので、サービスの
  ファイルを動かしても消えない。ただし、サービスへ戻る入口が無い状態では
  利用者はその画面へ再訪できない。

## 復元する場合

このディレクトリの中身を、`assets/brand/` を除いてリポジトリ直下へ
`git mv` で戻す。`assets/brand/` は文化案内と共有しているブランド資産の
出所なので、そのままドメイン直下の `assets/brand/` に置いておいてよい
（両サービスとも同じ資産を指すだけで、コピーが2つに増えるわけではない）。

戻したあと:
- `sitemap.xml` にこのサービスの4URLを戻す
- `.vercelignore` から `archive/` の除外を外す
- 文化案内側をどこか別のパス（例：`/machi/`）へ退避するか、共存させるかは
  そのときの判断による
