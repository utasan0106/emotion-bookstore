# 体験事例の調査と採否

確認日：2026-09-07。Web本文・公式解説を読んだ調査と、実際のブラウザ操作を区別する。下記一覧は全サイトを実機で再生できたという意味ではない。再訪率・満足度の比較実験は未実施。記事掲載、制作会社の実績説明、受賞はそれぞれ異なる根拠。

## 核として参考にする例

| 例・根拠 | 体験としての仕事 | 当サイトへの具体的な採用 | 採用しないこと |
|---|---|---|---|
| [Inside Abbey Road / Awwwards](https://www.awwwards.com/sites/inside-abbey-road)、[制作元](https://www.stinkstudios.com/work/inside-abbey-road) | 実在スタジオとその音・記録を同じ体験で扱う。Awwwardsの2015年5月4日Site of the Dayを確認 | 会場・音源・背景を一つの場面に置く | 受賞を再訪効果の証拠にしない。360度空間の再開発はしない |
| [INDUSTRIAL JP](https://idstr.jp/jp/) | 工場の映像・音と音楽制作が直接つながる | 実際の場所と実際の演奏という因果のある組を選ぶ | 無関係な景色へBGMを重ねて街の音楽と呼ばない。映像・音源転載なし |
| [Bear 71](https://bear71vr.nfb.ca/)、[NFB制作背景](https://blog.nfb.ca/blog/2012/09/18/where-bear-71-came-from/) | 記録資料に自分の操作で触れながら物語を辿る | 利用者が順序を選べる短い場面と、明確な終点 | 監視・追跡・VR技術自体を目的化しない |
| [Radiooooo](https://radiooooo.com/) | 国・年代を選ぶ操作が、聴ける音楽に変わる | 関係の選択を、再生対象の変化へ直結させる | 全世界の地図、無限ラジオ、独自に確かめていない地理分類 |
| [WindowSwap](https://www.window-swap.com/) | 実際の窓景色への入口が短い | 一つの大きな場面。場所と記録日時を見失わせない | 延々とランダムな景色を送る仕組み |
| [Neal.fun Ambient Chaos](https://neal.fun/ambient-chaos/) | 操作に応じて音環境を変える | 音を操作した結果がすぐ分かること | 許諾のない音源のミックスや効果付け、見せかけの波形 |
| [Musica Terra Playground](https://musica-terra.com/interactive/)、[Jazz History Map](https://musica-terra.com/interactive/jazz-history/) | 音楽史の関連を辿り、試聴へ進める | 人・作品・時間の関係から聴く | 表示される全関係を未確認で事実として流用しない。Atlasのタブ構造へ戻さない |

音楽と映像は単に同時に出せばよいわけではない。今回選んだSHELTER音源は、録音会場を公式が支える。ソロ盤の場所や選曲理由は別途根拠が必要。

## 共有された参考サイトの扱い

| 参考 | 読み取った用途 | 今回の判断 |
|---|---|---|
| [Global Nature Watch](https://globalnaturewatch.org/) | 自然の観測から理解・行動へ向かうサービス | データを現実の行動へつなぐ原則のみ参考。完全なUI操作は未検証 |
| [Windy](https://www.windy.com/)、[公式API説明](https://api.windy.com/map-forecast/docs) | 時間・地点・層の変更と表示の対応 | 時点のラベルを徹底。天気APIや地図導入はしない |
| [Virtual Vacation](https://virtualvacation.us/) | 歩く・走る・飛ぶなど体験の動詞から映像へ入る | 「読む」一択ではなく、聴く・見るで始まる入口にする |
| [Neal.fun](https://neal.fun/) | 一つの操作と驚きに焦点を絞った作品群 | 小さく完結した編集回。大量ミニゲーム化しない |
| [Project Gutenberg](https://www.gutenberg.org/) | 電子書籍を実際に読む・入手する | 将来の作品実体験候補。米国でのpublic domain説明を日本・翻訳・音源に自動適用しない |
| [Open Culture](https://www.openculture.com/) | 背景の編集と実際の文化資料へのアクセス | 背景と実物を近くに置く。紹介記事を再利用許諾扱いしない |
| [Open Library](https://openlibrary.org/help/faq/reading)、[提供先一覧](https://openlibrary.org/trusted-book-providers) | 本の発見と読める／借りる／試し読み等の状態 | 利用可能な行動を区別。書誌があるだけで読める表示にしない |
| [Stowaway](https://stowaway.live/) | 現実の移動データから描いた窓の景色 | 記録・現在・再現の区別を借りる。映像を実カメラの中継と誤認させない |
| [GeoLibre](https://geolibre.app/)、[作者の紹介](https://gishub.org/blog/geolibre/)、[チュートリアル](https://www.youtube.com/watch?v=lbioujkDSG0) | ブラウザで地理参照する編集作業 | 編集者の将来ツールとしてHOLD。権利のある地図、基準点、残差を検証する用途。残差が小さくても歴史的主張が正しいとは限らない。PLATEAU再開発なし |
| [MEFILASの音楽事例集](https://note.com/mefilas/n/n1fe9d4e14774) | 音楽サイトの操作・演出の事例集（2021年） | INDUSTRIAL JP等を一次情報へ辿る入口。SIRUP・Poolsuite・JazzKeys等は着想資料。掲載を「高評価の実証」としない |

[相鉄レコードの公式アーカイブ](https://www.sotetsu.co.jp/news/archive/2021/)には公開終了表記がある。過去のよい着想と、現在利用できる出口を区別する。古い紹介記事の掲載先をそのまま現行リンクとして採用しない。

追加5本は新機能の仕様書ではなく、設計と評価の補助資料。将来の英語対応は原題・地名・操作ラベル・実際の出口から始める候補とし、現段階で全文AI翻訳や全国情報を増やさない。

## 権利・出典を守る転用

画像はWikimedia Commonsの各FileページまたはUnsplashの個別ページと利用条件を照合する。今回は既存のCC0会場写真を再利用。ジャケット、映画スチル、音源、字幕を無料素材とみなさない。配信元の公式プレイヤー内に表示される画像は埋込の一部として扱い、ローカルへ抽出しない。

[Bandcamp公式埋め込み案内](https://get.bandcamp.help/en/articles/15263071-how-do-i-create-a-bandcamp-embedded-player)を読み、両権利者ページのShare / Embedから生成されたコードをブラウザで照合した。再配信権や広告なし再生保証を得たわけではない。公開前には新providerの通信・Cookie等を調べ、同意説明とTrustを整合させる。
