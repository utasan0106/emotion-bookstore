## 今回の一つ

『PARKS パークス』の公式予告を観て、気になった音の背景を選び、同じ映像へ戻れるようにする。見方の手掛かりは編集部の提案であり、視聴者の感情・理解の推定ではない。

下北沢の音楽試作は前回の公開ゲートを維持する。ローカルHTTP / file URLのブラウザ制限を迂回せず、実機QAは未完了。今回の開発は、その未確認を解決したという意味ではない。既存音楽試作と共通の公開面を作らず、PARKSのソースとプレイヤー接続だけを前倒しした。

## 体験と画面の契約

- 390 / 430px：サイト名、吉祥寺、見出し、短い導入、1分59秒の公式予告。動画の操作を長い本文より先に置く。プレイヤーは200px以上の高さを確保する。
- 1440px：予告を中央に大きく置く。背景欄は左に問い、右に三つの開閉項目。下部で写真と作品・公園への出口を並べる。
- 予告は1本。最初は同一オリジンの文字・CSSのみ。YouTubeサムネイルのhotlink、preconnect、iframe先読みはない。
- 既存 `video-embed.js` を変更せず再利用。利用者が明示的に開き、YouTube内で再生する。共有UIで確認した動画IDを使う。自動再生・ループ・playlist・SDK追加・偽の再生進捗はない。
- Native controls / fullscreen / keyboard / picture-in-pictureを残す。`rel=0` は関連動画の完全非表示ではなく、同じチャンネルに限定するパラメータ。提供元UI全体の有限性は保証しない。
- 背景はnative detailsで任意に開く。全問を読むことや視聴完了を先へ進む条件にしない。予告へ戻るリンクは既存プレイヤーを再作成せず、視聴位置を変えない。
- Founder追記を反映し、第3の背景に2017映画 → 2016アルバム → 2014セッション → 2012上映との演奏という逆順の来歴を加えた。録音・発売・使用という別の関係を分け、年代スライダーや自動再生は増やさない。
- 閉じて停止、公式サイトやThreadへの通常クリック、pagehideでiframeをDOMから外す。再度開く場合は先頭からのプレイヤーになる。実音停止は実機QA待ち。
- プレイヤー失敗時も公式YouTubeへのリンクを常設。共有ローダーが未取得なら読み込みボタンを隠したままにする。JavaScriptなしでも背景・公式出口を使える。
- 井の頭池写真は下部に置き、予告の場面写真の代用にしない。2024年撮影、作者、CC BY-SA 4.0、既存の縮小を表示。

## 通信・Trust

既存本番のCSP、Privacy文言、Measurement定義は変更しない。新しいproviderは追加しない。試作には解析スクリプト、保存、private入力、カメラ、位置情報はない。

YouTube iframeは既存部品と同じ `strict-origin-when-cross-origin`。通常のHTTPS間では参照元はoriginのみとなり、ページのpath/queryは送らない。IPなどの通信情報やprovider側処理が存在する点を操作の近くに説明する。プライバシー強化モードを「外部通信なし／追跡ゼロ」と呼ばない。公開時の実通信確認は別ゲート。
