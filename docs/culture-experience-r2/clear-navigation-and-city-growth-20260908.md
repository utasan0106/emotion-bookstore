## 今回の実装

- HOME 冒頭は、既存の二つの音・映像体験への入口。一つだけ残す高円寺の読み物リンクは、その紹介欄に置く。
- HOME の本・映画・音楽・映像には街名を添え、その作品の個別ページへ直接進む。
- works.html は四つの短い作品案内。紹介や背景を積み上げず、一作品につき一つの個別ページへの入口を置く。以前の #book / #film / #music / #video は一覧の該当作品に残す。
- work-book.html / work-film.html / work-music.html / work-video.html は一作品だけ。街との関係を「物語の舞台」「撮影された街」「ライブが録音された街」「踊りが行われた街」と区別する。
- 個別ページには「作品を選び直す」。紹介本文・一次資料・公式出口は既存の検証済み内容を保持する。音楽は背景の前に聴き比べへの入口を維持する。
- 棚の「今週の特集」は「この街のイベント」。展示・演劇・ライブ・展示販売の種類、街、期間状態、日程、会場を表示する。「開催期間内」は休館日や開演時刻までを保証する表示にせず、公式で確認する案内を添える。終了した催しは従来どおり非表示。
- 棚の作品詳細で、公式の行き先と事実の出典が同じ URL の場合、出典欄は「上の公式ページ」として同一 URL のリンクを重ねない。
- 高円寺は「高円寺の踊りは、どう始まった？」。冒頭に商店街での始まりと木場連との出会いを明記。章は内容を表す見出しにし、1957／はじまる・1963／名を変えるを章と本文の両方に置かない。四つの関係の年・動詞・証拠は本文の同じ形式で保持する。

対象は本文中の主行動。ブランドのホームリンク、メニュー、戻る、停止、資料の参照は役割が異なる。すべてのリンクを機械的に一つに制限しない。今後も同じ目的地を複数の大きな CTA にしない。

## 編集と生成

既存の四作品の本文は tools/work-entry-source.html に保存。編集後に `node tools/build-work-pages.js` で一覧と四つの静的ページを生成し、生成結果もコミットする。`node tools/build-work-pages.js --check` は編集元と配信ファイルのずれを検出する。ブラウザ上で元 HTML を取得・分割しない。元 HTML は .vercelignore で配信対象外。

qa/works_check.js は従来の詳細な編集内容・関係・権利の契約を編集元に対して保持。qa/work_page_check.js は実際の生成ページを別途確認する。旧一ページを前提にした qa/works_browser_qa.js はページ遷移の新契約に更新。ブラウザ検査は未実行。
