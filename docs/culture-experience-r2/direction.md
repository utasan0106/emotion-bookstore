## Product definition / DECISION

**街と作品を行き来し、実際に聴く・見る・触れることで、文化のつながりを自分で発見する場所。**

入口を「説明を読む」から「一つの音・場面・作品に触れる」へ移す。Threadは、その後に生まれた「なぜ？」に答える。文章、出典、公式の出口は体験を支える。

Founder追記（2026-09-07）：テキストの量ではなく、音・映像・自分の操作で実感できる接点を増やす。インタラクティブアートからは「行為が対象を変える」「結果を自分で感じる」を採用する。最初の操作前に長い背景説明を要求しない。資料が裏付ける街との関係、撮影・録音時期、素材の権利は維持する。

吉祥寺試作では映画予告と100周年記念の公園放送記録を選べるようにした。4街の調査と、体験素材を採用できる範囲は [city-culture-research-r1.md](city-culture-research-r1.md) に整理する。音や写真の印象だけを根拠に、街同士の文化的影響を線で結ばない。

Founder共有のアート・ゲーミフィケーション資料を踏まえ、**短い誘い → 自分で選ぶ → 実際の音・場面を確かめる → 気づいたら選び直す／現実へ出る**を設計原則として採用する。これは当サイトへの設計上の推論であり、再訪や学習効果の実証ではない。小さな問いには採点を付けず、映像・出典・出口は初めから利用できる。ポイント、連続訪問ボーナス、ランダム報酬、視聴による解放条件は導入しない。参照資料の確認範囲と採用判断は上記調査文書に記録した。

「すごい」の核は、派手な都市表示ではなく、知っている曲が実在する街の出来事として聞こえ直すこと。「また来たい」は、気になった演奏をもう一度聴く、新しい編集回に触れる、現地へ行く前後に戻る、という自発的な理由で作る。再訪が増えるかは未検証の仮説。無限再生・ランキング・診断・個人別推薦・通知強制で作らない。

## 最初の一回：下北沢、同じ曲をふたつの演奏で

**FACT**：Boris公式は2007年2月4日のSHELTER公演を『Rainbow』発売記念公演と記す。ライブ盤の3曲目は「Time to Go -夕暮れのジャイロ-」。Pedal Recordsの『SUNSET NOTES』にも同曲がある。出典は `media-provenance.json`。

**EDITORIAL DECISION**：この二つを往復する。共通曲の聴こえ方を利用者自身で比べる。音の差・感情・選曲理由・ソロ盤の録音地は推定して書かない。

**HYPOTHESIS**：ライブ盤を単にリンクするより、会場の写真と演奏を同時に見聞きして、別演奏へ切り替えるほうが、場所と作品の接点を実感できる。

### 体験の絵コンテ

1. SHELTER入口の写真と「同じ曲を、ふたつの演奏で。」を見る。写真は2022年のもので、公演は2007年と区別される。
2. A＝SHELTERライブ、B＝ソロ盤から選ぶ。選択は通信を起こさない。
3. 説明を確認して公式Bandcampプレイヤーを開き、その ▶ で再生する。初回の音まで2操作となる制約を明示する。
4. もう一方を選ぶと前のiframeを破棄して停止する。もう一方のプレイヤーを開いて聴く。自動の同位置シークやクロスフェードはしない。
5. 興味があれば「なぜ、このふたつ？」を開く。最後はSHELTER公式公演情報か下北沢の棚へ。これで一回が終わる。

Native playerのアルバム移動・購入・共有等は提供元の機能として残る。サイトが編集する選択肢は二つだが、提供元の全機能や曲末後の挙動を制御できるとは言わない。

### Visual contract

- Desktop：左に実際の会場写真、右に見出し・2選択肢・一つのプレイヤー。最下部に公演情報への出口。
- Mobile：写真、同曲比較の見出し、A/B、プレイヤーの順。文脈は折りたたむ。自動音声、スクロール固定、ドラッグ必須、装飾波形は無し。
- 素材自体が主役。黒・生成り・濃緑の抑えた配色。音声に合わせたように見せる架空のエフェクトは作らない。
- 説明を読まなくても選択は可能。音を出せない場合にも作品名・演奏者・関係と公式出口が分かる。
- 390 / 430 / 1440、200%表示、キーボード、低速・外部プレイヤー拒否時を公開前に確認する。

## 次の開発順序

継続checkpoint：吉祥寺の独立映像試作を追加した。詳細は `parks-screen-r1.md`。下北沢・吉祥寺とも実機QAが残るため、他の街へ試作を増やす前にこの2件を通して確認する。まだPublic Journeyへ接続しない。

### Founder追記：映像から街のカルチャーを遡る

**採用**。「映像で触れる → 生まれた場所・担い手を知る → その後に残った作品・商品へ → 今、聴く・観る・訪れる」を体験の編集単位にする。商品は売上・人気の指標ではなく、文化が持ち帰れる形になった接点として扱う。

最初の吉祥寺では、2012年の映画館での演奏、2014年のセッション、2016年のCD・レコード・カセット、2017年の映画を、逆順で遡る。年代ごとの映像が揃ったわけではない。公式予告は2017年作品の入口として使い、過去の公演を映した記録と誤認させない。

今後の街ごとの適用：

| 街 | 映像から始める候補 | 確かめる文化の来歴 | まだ断定しないもの |
|---|---|---|---|
| 吉祥寺 | PARKS公式予告（今回の独立試作） | 映画館の演奏・セッション → アルバム → 映画 | 都市全体の若者文化や他都市への影響 |
| 下北沢 | LADY JANEの公式映画映像（次の候補） | 店に集まった人々・音楽 → 記録映画 → 現在の店や作品 | 公式動画ID・利用範囲の未確認分、人物の発言・世代の推定 |
| 高円寺 | 既存の主催者公式踊り映像 | 現在の踊り → 出典が支える継承の経緯 | 現在映像と1957年の街を同一視すること、地理座標 |
| 神保町 | 森崎書店の映画予告・出版社の試し読み候補 | 本 → 映画 → 書店街での作品体験 | 作中の書店と実在店を同一視すること、本文・朗読の権利 |

「若者が何を発信したか」は当時の年齢・当事者の活動記録がある時に扱う。トクマル氏の10代と公園の縁のような本人の説明は採用できるが、暦年は補わない。「他の街・文化へ波及」は、共演・出版・上映・移動などの接点に根拠がある時に追加する。時系列の前後関係だけで影響の矢印を作らない。

採用前に、公式動画／権利、発信者・年代、関係の出典、残った作品・商品、現在使える公式出口を揃える。映像の操作と背景を読んだ後の再視聴に意味があることを検証し、映像が装飾として付いただけのページを増やさない。

| 順 | 街・媒体 | 実際に行うこと | 着手・公開ゲート |
|---|---|---|---|
| 1 | 下北沢 / 音楽 | SHELTERライブとSUNSET NOTESの同曲比較 | この試作。実端末の再生・停止・横幅とBandcamp通信説明を確認 |
| 2 | 吉祥寺 / 映画と音楽 | 『PARKS』の公式映像を見て、音楽制作の問いから演奏・背景へ進む | 権利者の公開動画ID・埋込可否・字幕を確認。脚本段階、トクマル氏起用、結末の説明は制作当事者の出典ごとに分ける。映像の転載・勝手な再編集なし |
| 3 | 高円寺 / 踊り・映像 | 現在の公式踊り映像を先に見る。踊りの継承を気になった箇所からThreadへ辿る | 既存公式映像を再検証。1957との同一場面・正確な地点を捏造しない |
| 4 | 神保町 / 本と映画 | 正式な試し読み、朗読または予告を選んで作品に触れ、原作と映画の関係へ | 出版社許諾・版・翻訳・朗読音源の権利、公式提供方法が揃ってから。GutenbergやOpen Libraryの存在だけで本文を移植しない |

下北沢のLADY JANE記録映画は第2段階の映像型を適用する候補。四街同時増産はせず、一つの型が役立つことを確認して展開する。

他の街・文化・時代への接続は、`recorded_at / performed_at / adapted_from / learned_from`等の出典がある関係だけ採用する。「似た雰囲気」は編集上の提案として明示しても歴史的な関係線にはしない。

## 公開前の最小判定

1. 初見の人が5秒で「二つの演奏を聴き比べられる」と理解し、音を出す操作を見つける。
2. 実際の音源が二つとも再生でき、選び直す・閉じるで音が重ならない。再生不能でも公式へ進める。
3. 利用者が写真の撮影年、公演の年、ソロ盤との関係を取り違えない。
4. 説明を聞かずに「音源を聴いた後、SHELTERでの公演が気になった」など具体的な接点を一つ言える。
5. 任意の小規模ユーザーテストで、もう一度使うなら何のためかを聞く。再訪を約束する発言や長い滞在時間だけでは成功扱いしない。

この5項目が成立しなければ、グラフ・地図・大量コンテンツで穴埋めせず、最初の体験を見直す。
