# まな：実写の世界にアニメが入る制作基準

更新：2026-09-08。ユーザーの最新の画像・発言を優先する。

## 表現の目的

**実際の街の映像の中に、線画で描かれたまながいる。作品を見つけ、振り向き、次の寄り道へつなぐ。**

背景の街は実写を維持する。まなの顔・髪・服はアニメの線と色面を維持する。接地、同じ光の方向、実寸に合う大きさ、物の前後関係で両者をつなぐ。まな自身を写実的な人形に近づけない。

### 最新の修正履歴

- 丸眼鏡・エプロンドレスの初案は不採用。ユーザーは可愛さと衣装を指摘した。
- ピンクのカーディガンの立体的な案も、そのまま採用しない。柔らかな顔の雰囲気は参考に残す。
- 単に陰影を減らした平面的な案も方向違い。線・表情・光・空間を一緒に調整する。
- IMG_4966〜4972、13:59のスクリーンショットは画調の参考。14:04の実写とアニメの共存画像は合成の考え方の参考。参照人物・既存キャラクター・衣装をそのまま複製しない。
- 最新の試案は茶色の髪、青灰色のブルゾン、生成りのトップス、チャコールのスカート、赤茶のバッグ。服・顔の完成承認はまだ得ていない。
- 架空の街全体を描いたイラストはキャラクター検討資料。実写への合成が現在の体験目標である。

## 登場範囲と街の代表写真：最新指定

- まなの主な登場場所は街のライブストリーミング映像内部。通常ページの常駐案内役にはしない。ほかの登場も必要な場面に限り、短く控えめにする。
- 初期は利用者の表示操作で6〜8秒の一動作。自動の反復登場は入れず、終了後は消える。停止・非表示を常に優先する。
- 原画・写真合成の制作確認ページは、この登場範囲とは別の非公開資料。写真や録画を本番のライブの代用にしない。
- 街の入口には通り・街区全体を見渡せる写真を選ぶ。一店舗の看板が主役になる写真は街の代表として使わない。店を取り上げる場合は作品・催し・歴史との関係を説明できる個別ページで扱う。
- 神保町の主画像はビンテージの店舗正面から、Fred Cherrygarden撮影のすずらん通りへ変更。元画像は撮影時の記録であり現在の状況とは表示しない。
- 最新の画調シートは `assets/mana-style-sheet-r2.png`。輪郭とセル影を明瞭にした全身・3表情の候補。微笑みと発見の表情差、髪の細線の整理には改善余地があり、最終承認とは扱わない。

## 次に制作する1カット

固定したカメラの実写映像で、まなが2歩進む → 本や看板に気づいて止まる → 視線と顔を少し返す。最初は6〜8秒程度の一場面に絞る。

1. 原画：顔の斜め、閉眼、視線、左右の足の接地ポーズを揃える。輪郭・服・体格の一貫性を優先する。
2. パーツ：顔、前髪、後ろ髪、左右の目・瞼、口、胴体、腕、脚、服、バッグを分け、動くと現れる部分を描き足す。編集原本と出力用画像を分けて管理する。
3. 動作：表情と小さな揺れは2Dのメッシュ変形・回転で試す。歩行や大きな振り向きは専用のポーズと補間を用意する。1枚の絵の拡縮だけで代用しない。
4. 合成：カメラごとに地面の位置、縮尺、足元の影、静的な前景マスク、光の方向を設定する。看板の後ろを通る短い動作で前後関係を確かめる。
5. 確認：足滑り、手足の形、顔の変化、髪のちらつき、前景の隠れ方、昼夜の色、スマホでの読みやすさを確認する。

2Dパーツ・変形の根拠：[Live2Dの素材分け](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)と[デフォーマ](https://docs.live2d.com/en/cubism-editor-manual/deformer/)。工程の参考であり、特定ソフトの購入・導入・無償商用利用が決定済みという意味ではない。

## ライブへ接続する条件

初回は固定カメラ1箇所。配信状態、場所、合成・Web配信が可能な利用条件が確認できた素材を使う。自分たちの映像、または合成が認められた配信元からの入力を優先する。

YouTubeの標準埋め込み上にまなを重ねる方式は使わない。[公式仕様](https://developers.google.com/youtube/terms/required-minimum-functionality)はプレイヤー前面の重なりを制限している。将来の合成窓には、合成用の映像を扱える入力経路が必要。

固定看板などの前景は手作業のマスクから始める。通行人・車との動的な前後判定、カメラ移動追従、昼夜自動補正は追加工程。任意のライブに無調整で配置できると約束しない。ライブ内容をAIで毎フレーム描き直さない。

現在の4街について、現行配信・場所・埋め込み／合成可否まで確認済みの採用映像は0件。試作にはライブ表示を付けない。非公開・終了・期限切れを検出した窓は停止し、別の無関係な場所で埋めない。

## 体験と運営

まなは任意で表示・停止できる。非表示でも作品と街を探索できる。音声の自動再生、顔や感情の推測、無制限のチャットを初期機能にしない。

地図・街・催しを案内する一言は確認済みの台帳から選ぶ。まなの発言で開催中・現地の混雑・人の気持ちを創作しない。連続配信の維持費用・確認作業が未測定なので、全街常時無料運用できると宣言しない。

まなの実装は独立して進める。本体は「作品との出会い → 街・カルチャー・いまの催し → 想いを持ち帰る」を優先する。週替わり更新の完走と公開動画の実再生検証を先送りしない。
