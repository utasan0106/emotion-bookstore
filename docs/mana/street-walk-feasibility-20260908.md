# 街を歩く体験：方式の判断

確認日：2026-09-08。実装案の調査記録。ライブ接続・歩行映像が完成したという記録ではない。

## 採用する考え方

「街を少し歩く → 作品や今の催しに出会う」という短い体験にする。自由に延々と歩く地図サービスを作ることは目的にしない。最初は1街・3地点、約1分で一つの発見へ進める構成を検討する。高円寺は既存データがあるため技術確認候補になるが、サイト全体を代表する街として扱わない。

## 方式と役割

| 方式 | できること | 判断 |
| --- | --- | --- |
| Street View公式表示 | 撮影地点のパノラマを見回し、隣の地点へ移動する | 周辺の実景を確認する用途。画像を保存してつなぎ直す素材源にはしない |
| 許諾済み360度写真・歩行動画 | 自分たちの画面で地点の接続、移動、作品との出会いを演出する | 写真の世界を歩く体験の主候補。撮影時期と非ライブ表示が必要 |
| PLATEAU | 建物や道の立体的な位置関係を扱う | 自前の実写・パノラマと組み合わせる空間の下地候補。Google画像を建物のテクスチャにしない |
| ライブ映像 | 今の人や街の動きを見る | まなの主な登場場所。必要なときに短く登場し、通常ページには常駐しない |

公式Street Viewは隣接パノラマ間を移動できるが、連続した歩行映像そのものではない。Maps JavaScript APIには位置と視点、隣接リンク、オーバーレイの機能がある。オーバーレイ対応を、人物の足の接地や建物による遮蔽まで自動で解決できる意味に解釈しない。[公式仕様](https://developers.google.com/maps/documentation/javascript/streetview)

Maps Embed APIにはStreet Viewモードがあり、利用料金は無償だがAPIキーが必要。JavaScript APIで作る独自のパノラマ表示とは課金体系を混同しない。今回はキー・課金設定・新規外部接続を追加していない。[埋め込み仕様](https://developers.google.com/maps/documentation/embed/embedding-map)、[Embedの料金](https://developers.google.com/maps/documentation/embed/usage-and-billing)、[JavaScript APIの料金](https://developers.google.com/maps/documentation/javascript/usage-and-billing)

Google Maps Platformの標準規約は、画像の抽出・再配信・許可外のキャッシュ、Googleコンテンツからの派生作成、および非Google地図との併用を制限する。そのためStreet View写真の回収・動画化・PLATEAUへの貼り付けや同じ画面での同期合成は採用しない。独自の空間演出には許諾済み素材とPLATEAUを使う。[公式利用規約 3.2.3](https://cloud.google.com/maps-platform/terms)、[サービス別規約](https://cloud.google.com/maps-platform/terms/maps-service-terms)

PLATEAUは商用利用も可能なオープンデータ。各データのライセンス・出典表示に従う。無料の都市データであっても、配信・変換・保守の工数や費用までゼロになる意味ではない。[国土交通省の案内](https://www.mlit.go.jp/plateau/start-guide/)

## 既存資産と足りないもの

リポジトリの `/atlas/data/` には高円寺周辺の建物1,045件、道路341件のGeoJSONがある。建物は平面形状と計測高さ、道路は平面形状。外壁テクスチャ・歩道の段差・通行可能な経路・360度写真は含まれない。押し出し表示の試作に再利用できる可能性はあるが、写真のような街をそのまま再生できるデータではない。

出所は `tools/plateau/README.md` と `koenji/source-manifest.json` に記録された杉並区2025年度データ。今回G空間情報センターの個別データページは取得できず、配布状態の再確認は未了。手元データの属性と件数は直接確認した。

## 開発順と判定

1. 1街・3地点の素材候補と、各地点から出会う作品・催しの掲載理由を決める。隣接関係が確認できない写真を連続した道としてつながない。
2. 許諾済みの360度写真または連続歩行動画を確保し、「進む・戻る・閉じる」で短く体験できる試作を作る。素材がない段階は架空の街写真を実景として補わない。
3. 必要な範囲だけPLATEAUと位置・高さ・カメラを合わせ、2Dのまなの接地・遮蔽を確認する。まなを3D人形の見た目に戻さない。録画内への登場はライブ内の主用途を補う検討枠とする。
4. モバイルで画面酔い、待ち時間、文字の重なりを確認する。自動移動を強制せず、動きを減らす設定では静止した地点選択を提供する。
5. 一つの作品や旬の催しへの発見が増え、操作が理解できる場合に拡張する。写真一覧より遅いだけなら立体表示を採用しない。

ライブ・録画・撮影時点の写真・3D再現を明示し、閲覧者の現在地の取得は初期仕様に含めない。まなは映像体験の内部で短時間、終了・停止・画面外で非表示。全ページ共通のマスコットにはしない。
