# 見出しと記事の入口の修正（2026-10-23）

## 判断

- [BRUTUSの記事](https://brutus.jp/post-531740/)で確認した、具体的な見出し・導入・写真とクレジットをつなぐ構成を参考にする。サイトの配色やレイアウトを複製するものではない。
- [Hanakoの記事](https://hanako.tokyo/health/519175/)のように、写真の場所・被写体と本文の関係を明確にする。既存の許諾済み街写真を使うが、広告資料や線路跡地を撮影した写真であるかのようには見せない。
- [POPEYEの記事](https://popeyemagazine.jp/post-298539/)の、読み物と末尾の情報を分ける構成を参考に、記事本文と出典への導線を維持する。架空の訪問記、取材や発言、営業案内は追加しない。

参照サイトのモバイル画面や余白を実測した結果ではなく、取得された記事構成に基づく設計判断。

## 実装

1. 題名を意味のある短いまとまりに分ける。空白や強制改行は追加しない。通常幅ではまとまりごとに折り返し、文字拡大でまとまり自体が収まらない場合のみ内部の折り返しを許す。
2. 既存の書体・文字階層を維持。新しいフォント、装飾的な背景、文字の画像化、行数固定、省略は追加しない。
3. 2記事に街の写真を追加。写真に文字を重ねず、全体を表示し、吉祥寺写真の撮影者表記も切り落とさない。場所・記録年（確認できる場合）・記事との関係・作者・ライセンスを写真下に示す。
4. 広い画面は見出し・導入と写真を並べ、その下に要点を置く。狭い画面では題名、写真、導入、要点の順に読む。本文は白い読み面のまま保つ。
5. 記事本文の事実・題名・出典は変更しない。AI利用の方法説明は出典節に残す。RSSは所有者方針により、案内・メタデータ・フィード・生成処理をすべて撤去する。
