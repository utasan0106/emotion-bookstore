# 市場調査・評価用プロンプト

Web にアクセスできるツール（ChatGPT / Claude の検索あり環境など）に貼って使う。
この repo の作業環境は外部サイトへ接続できないため、調査は外で行う。

事実部分（件数・仕様）は 2026-09-10 時点。数字を更新するときは
`node qa/catalogue_supply_check.js` と `node qa/event_supply_check.js` の出力で置き換える。

## 貼り付けるプロンプト（ここから）

あなたは、消費者向けWebサービスの事業評価を専門とするアナリストです。
以下のサービスについて、**市場での立ち位置・あるべき姿・現時点の評価**を調べて報告してください。

### 前提となるルール（最優先）

1. **お世辞を書かない。** 良い点より先に弱点を書いてください。私は投資判断ではなく、
   改善のために読みます。褒めるだけの報告は無価値です。
2. **事実と推測を必ず区別する。** 競合サービス名・利用者数・市場規模を挙げるときは
   **URLか出典を併記**してください。出典を出せないものは「未確認の推測」と明記する。
   **存在しないサービス名や数字を作らないでください。**
3. **Webを見られない場合は、最初にそう宣言**したうえで、全体を「未検証」と断って書いてください。
4. 実物は https://emotionbookstore.com/ で公開中です。**必ず実際に開いて確認**してください。
   開けない場合はその旨を書いてください。

### サービスの説明

**「みんなの感情書店」** — 人が選んだ文化を、有限に並べて案内するWebサイト（日本語・東京）。

読者は「街」または「作品」から入り、本・音楽・映像・映画をたどり、
最後は**公式サイト・配信元・劇場・書店・映画館といった「現実の行き先」へ出る**。
サイト内で完結させないことを設計思想にしている。

**現在の中身（2026-09-10 実測）**

- 街4つ：高円寺・下北沢・吉祥寺・神保町
- 作品77件：本16 / 音楽20 / 映像23 / 映画18（＋街をまたぐ短編3）
- 街の文化イベント24件（15会場）：演劇8 / 映画6 / 本・トーク12 / 展示3 / ライブ4
- すべて編集部が個別に選び、**街との関係を出典で説明できるものだけ**を載せている
- 週替わりで見せる順を入れ替える

**技術・運用**

- 静的サイト（Vercel）。ログイン・アカウント**なし**
- **利用者が書いた内容**（「想い」のスタンプ・文章、「気になる」）は端末の localStorage のみ。
  サーバー送信も計測もしない
- **利用状況**は GA4 で限定計測する。Cookie等の識別子、閲覧・操作イベント、端末情報、
  IPから推定されるおおよその地域、参照元を扱う（`_ga` Cookie は60日）。
  「利用者のデータを一切外部送信しない」わけではない
- **Amazon アソシエイトと楽天アフィリエイトを利用している。** 購入リンクに紹介識別子を含む
  場合がある。ただし**掲載の採否・並び順には影響させない**という原則を掲げている
- 広告枠の販売・読者課金は**なし**。収益モデルとしては未確立
- 個人（ファウンダー1名）＋AIによる編集・実装体制

**このサービスが「やらない」と決めていること**（ここが競合と最も違う点）

- 無限スクロールのフィードにしない
- 人気順・ランキング順・広告順で並べない
- AIによる好みの予測・レコメンドをしない
- 心理分析・感情スコアリング・診断をしない
- 連続記録・バッジ等のゲーミフィケーションをしない
- 裏付けのない「この街とこの作品の関係」を出さない

**自覚している弱点**

- 在庫が薄い。特に展示3件・ライブ4件
- イベントは会期で消えるため、補充しないと空になる
- 収益モデルが未確立（アフィリエイトはあるが主収益になっていない）
- 認知がほぼゼロ

### 答えてほしいこと

**1. 市場での立ち位置**

このサービスは日本で誰と比較されるのか。**実在する競合・代替手段を最低8つ、URL付きで**挙げ、
それぞれについて「どこが重なり、どこが違うか」を1〜2文で書いてください。
比較対象は同種サービスに限らず、**利用者が同じ目的で実際に使っているもの**を含めてください
（検索エンジン、地図アプリ、SNS、雑誌、紙のガイドブックなども対象）。

確認の出発点として次を挙げますが、**適否は自分で判断し、不適切なら外して他を足してください**：
Tokyo Art Beat / 散歩の達人 / 東京人 / Time Out Tokyo / ことりっぷ / Atlas Obscura /
Are.na / Google マップ / Peatix / BRUTUS・Pen 等の雑誌特集。

そのうえで、**このサービスが実際に勝てる可能性のある領域**を特定してください。
「独自だから勝てる」ではなく、「**誰のどんな場面で、既存の選択肢より明確に優れるか**」で
書いてください。優位が見つからないなら、**見つからないと書いてください。**

**2. どうあるべきか**

- この方向（人力編集・有限・非アルゴリズム）は、2026年の市場で**追い風か向かい風か。**
  根拠となる観測（他サービスの動向、利用者側の変化など）を出典付きで
- 現在の設計で**構造的に無理があるところ**はどこか
- **収益化の現実的な選択肢**を3つ。それぞれ「掲げている原則（人気順で並べない・
  広告順で並べない・アフィリエイト順で並べない）と両立するか」を明記してください。
  両立しないものは、そう書いたうえで挙げてかまいません
- 街を増やすべきか、今の4街を深めるべきか。理由とともに

**3. 点数**

次の8軸で**各10点満点**、合計80点満点で採点してください。

1. 価値提案の明確さ（初見で何のサイトか伝わるか）
2. 既存の代替手段に対する差別化
3. コンテンツの厚みと鮮度
4. 再訪する理由の強さ
5. 収益化の見込み
6. **運用の持続可能性**（個人＋AI体制で在庫を維持できるか）
7. 信頼性・誠実さ（出典の扱い、プライバシー、誇張のなさ）
8. 発見されやすさ（検索流入・共有されやすさ）

各軸について必ず次の3つを書いてください：

- **点数と、その点にした理由**
- **減点した具体的な理由**（「もう少し改善が必要」のような曖昧な表現は禁止）
- **1点上げるために何をすればよいか**（実行可能な単位で）

最後に**合計点**と、**もっとも点数が低い軸から順に、着手すべき順序**を書いてください。

### 出力の形式

日本語。各節に見出しを付ける。競合表は表形式。
**最初に「この報告のうち、実際にWebで確認できた部分／できなかった部分」を明記**してください。

## 使ったあとに

返ってきた報告は**そのまま正とせず**、次を確認する：

- 挙がった競合URLが実在するか。**存在しないサービスを挙げる例がよくある**
- 市場規模・利用者数に出典が付いているか
- 減点理由が具体的か。曖昧なら、その軸は評価されていないと見なす

過去の調査で実際に出た**誤り**も確認すること：

- 作品件数の数え違い（音楽は20件。一覧ページのリンク先ユニーク数で数える）
- 「棚ページがJavaScript前提」という指摘 → 誤り。街の棚は初期HTMLに本文と作品リンクを
  持つ静的ページ。JavaScript必須なのは `/saved.html`（端末内保存の閲覧用、`noindex,nofollow`）
  だけで、これは仕様どおり

このサービスは説明を誤読されやすい（「AIレコメンド」「感情日記」と読まれる）。
報告が前提から外れていたら、**採点ではなく説明の失敗**として扱い、
プロンプトの「やらないこと」の節を強めて再実行する。
