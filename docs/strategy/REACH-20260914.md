## 3. 診断

### (a) 表示回数が単調に低下している

```
9/01  6        ■■■■■■
9/03  4        ■■■■
9/05  3        ■■■
9/09  2        ■■
9/13  1        ■
```

Xは初期の反応（いいね・返信・滞在）を見て配信を広げる。
**反応0のまま配信が細る、下向きの循環に入っている。**
投稿を続けるほど表示が減る局面であり、頻度を上げても戻らない。

### (b) 漏斗は、入口の一段目で終わっている

```
Xの表示  1〜6
   ↓
クリック 0〜1
   ↓
セッション 1（7日間、Direct 1件）
```

**下流は壊れていない。** 表示に比例した数だけ来ている。
クリック率も、着地後の挙動も、この規模では良し悪しを言えない。
**母数が無いだけである。**

構造化データ・パンくず・RSS・llms.txt は、いずれも
「来た機械／来た人に正しく渡す」ための整備である。
**来ていないものを増やす働きは無い。**

### (c) 見えた6件に、サイトへのリンクが1本も無い

内訳は note 2件、Spotify 1件、リンク無し 1件、不明 2件。
**サイトの URL を持つ投稿は、見えた範囲に一つも無かった。**

GA4 の Organic Social が0であることは、**この観測と矛盾しない。**
リンクが無ければ、Xからの流入は原理的に発生しない。
（ただし §2 のとおり19件は未観測なので、「25件すべてにリンクが無い」とは言えない。）

## 4. `AUDIENCE-20260911.md` の三本柱を、この実測で評価し直す

| 柱 | 2026-09-11 の想定 | 2026-09-14 の実測後 |
|---|---|---|
| **A. 機械に正しく読ませる** | 私が毎週積む | **止める。** 積み増しても数字は動かない |
| **B. 戻ってくる理由をつくる** | 私が毎週積む | **止める。** 戻る人がまだいない。早すぎる |
| **C. 人のいる場所へ出る** | ファウンダー | **唯一動いていて、そこが詰まっている** |

### 柱A を止める理由

構造化データ・パンくず・llms.txt は、検索とAIに正しく読ませるための整備である。
**7日間の Organic Search は0。** 読ませる相手がまだ来ていない。
既に入れたものは有効なまま残る（維持費はゼロに近い）。
**新しく積むのをやめる**ということである。

### 柱B を止める理由

RSS・今週号は「一度来た人が戻る理由」である。
**28コホート全部で 日1=0、日7=0。戻る母集団がまだ存在しない。**
維持率の改善は、獲得がある前提の仕事である。順番が逆になっている。

### 柱C が唯一動いている

Xは動いている。**そして、そこが詰まっている。**
表示が細り、見えた範囲にサイトへのリンクが無い。

**ただし、ここは私の領域ではない。** 関係づくり（会場・書店・催しの主催者、
Xでの人との応答）はファウンダーの仕事である。`AUDIENCE-20260911.md` が
最初からそう書いていた。**実測は、その配分が正しかったことを裏づけた。**

私にできるのは、**表示が増えたときに流入になる形を用意しておくこと**だけである。
それは「これを出せば表示回数が増える」ものではない。区別して扱う。
