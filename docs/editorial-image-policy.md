# 読みものの画像選定

Founder指示：2026-09-07。無料の関連素材を優先する。

探索先は Wikimedia Commons と Unsplash を第一候補とする。

- https://commons.wikimedia.org/wiki/メインページ
- https://unsplash.com/ja

1. 作品・街との関係を確認できる被写体を選ぶ。一般的な公園・店内写真を実際の場所や映画の場面として扱わない。
2. 個々の画像の作者、原典URL、ライセンス、撮影対象、必要なcredit、加工条件を記録する。検索結果に「無料」と出るだけでは採用しない。
3. Commonsはファイル別ライセンスを確認する。ページ末尾のデータ用CC0を写真のライセンスと混同しない。
4. Unsplashは無料ライセンス対象の素材を選ぶ。有料のUnsplash+を無料素材として扱わない。人物・商標・写り込んだ作品などの追加権利にも注意する。
5. 権利者表示と必要な原典・ライセンスリンクは公開creditへ残す。縮小・cropなどの変更も記録する。無料利用でも著作権放棄と解釈しない。
6. 画像は既存assetを優先し、必要時のみローカル配信assetへ追加する。新しい外部画像APIやruntime hotlinkを導入しない。
7. 適切な写真がなければ画像なしで進める。関係のない写真で穴埋めしない。

確認資料：

- Unsplash License（2026-09-07確認）: https://unsplash.com/license
- CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/

今回の実例：井の頭池、Htanaungg、CC BY-SA 4.0。映画スチルではなく2024年の場所写真として表示。
