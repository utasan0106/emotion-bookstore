# サイト構造・文章の再点検

2026-09-09 / 対象：トップ、街の一覧、4街の作品一覧、読み物、催し、共通メニュー。

## 結論

コーナー数よりも、入口の呼び名と情報の順序が迷いやすさを生んでいた。新しいコーナーは増やさず、既存の入口を「街から探す・作品を探す・催しを探す・街の記事」に統一した。

文章は、吉祥寺・下北沢の調査記事を重点的に編集。本文より先に資料比較や長い年表が続く構成を改め、具体例と読み解きを先に置いた。事実の根拠と調査の限界は削除せず、本文から参照できる形で整理した。

## 企業メディアとの比較

公開ページの構造・文章を確認した比較であり、相手サイトの読了率や離脱率を測定したものではない。

| 比較先 | 観察したこと | 感情書店への反映 |
|---|---|---|
| [BRUTUS](https://brutus.jp/)（マガジンハウス） | 新着、動画、連載を見出しで分け、各一覧へのリンクがある。具体的な内容を記事タイトルで示す | 特集タイトルと常設の入口名を分ける。詩的なタイトルだけで一覧の種類を説明しない |
| [SUUMOタウン](https://suumo.jp/town/) | 地域・都道府県・テーマという探す軸と、日付・地域・タイトルが区別されている | 「街から探す」ページでは街の一覧を先頭にする |
| [SUUMOタウンのインタビュー記事](https://suumo.jp/town/entry/musako-mizunonatsumi/) | 導入で人物と記事の対象を示し、話題ごとの小見出しから本文へ入る | 吉祥寺の記事は又吉直樹を起用した広告の具体例から入り、事実と解釈を見出し・段落で分ける |
| [無印良品・ローカルニッポン](https://localnippon.muji.com/) | おすすめと新着を分け、地域・日付・記事タイトルを一組で扱う | 「街の記事」に調査記事と各街のコラムへの入口をまとめる |
| [ローカルニッポンの登り窯の記事](https://localnippon.muji.com/7905) | 書き手の立場、対象となる企画、話者が明示され、話題別の見出しがある | 編集部の提案を実測結果のように書かず、調査から分かることと未確認事項を明示する |

写真、ロゴ、記事本文は転用していない。文字サイズの数値は比較先の実測値ではなく、当サイトで検証した設定。

## 発見した問題と修正

| 問題 | 修正 |
|---|---|
| 同じ入口が「作品から入る」「作品の案内」「街と作品」などと呼ばれる | 主な入口4つを共通ナビゲーションにし、メニューの作品リンクも作品一覧へ統一 |
| 街の一覧に着いたのに映像・街の動き・調査記事が先に並ぶ | 4街の選択をページ先頭へ。既存の映像・街の動き・特集はその後に残す |
| 選んだ街の作品を見る前に、別の街への案内が現れる | 別の街の同ジャンルは、選択中の街の作品の後に移す |
| 調査記事と人物コラム、高円寺の歴史が別の入口に散らばる | 「街の記事」から、2調査記事・4街のコラム・高円寺の歴史へ進めるようにする |
| 本文より先に広告資料や長い年表を読む構成 | 導入→目次→本文→年表・比較→資料・出典へ並べ替える |
| 出典へ移動した後に読んでいた本文へ戻りにくい | 各出典に「本文に戻る」を設置 |
| 下部の固定ナビゲーションが本文に重なる | 通常のページ末尾へ移し、読み進める画面を覆わないようにする |
| 長い段落、抽象的な見出し、説明の重複 | 2記事の5節を中心に書き直し、冒頭の説明とトレンド案内も簡潔化 |

## 文言の例

| 変更前 | 変更後 |
|---|---|
| 一つの街を、一つの答えにしない。〈一覧の主見出し〉 | 街の記事 |
| 有名人が出ている。でも、街との関係は同じではない | 広告出演と、街で暮らすことは違う |
| 店を宣伝する広告が、街の過ごし方を集めていた | 又吉直樹の広告から、街の過ごし方へ |
| 用事が先の訪問も、街が先の訪問もある | 仕事で来る平日、買い物をする週末 |
| 特定の用事に先立って吉祥寺で過ごすことを選ぶ層 | 具体的な用事を決める前に、吉祥寺で過ごすことを選ぶ層 |
| 次に確かめたいこと〈未調査事項の説明〉 | まだ分からないこと |

## 検証

- 開発画面で、トップのメニュー→記事一覧→吉祥寺の記事→出典→本文への往復を実行。
- 記事→街選び→吉祥寺→映像一覧→催しの移動を実行。選択した街の映像の後に別の街の案内が現れることを確認。
- 同一ページを埋め込む検証用画面で320px・390pxを点検。390pxのトップでは作品部分の開始位置が約251px。320pxの共通リンクは2列で、各リンクの高さ約44px。
- 320pxの枠で本文の文字を200％に拡大。本文は32pxとなり、文書幅と表示幅が一致し、横方向のはみ出しなし。これはブラウザー全体のズームではなく、文字拡大の検証。
- 研究記事本文は通常16〜17px、行間1.95、最大幅42rem。見出し・本文・出典のサイズと段落間隔を分けた。
- `node qa/verify-product.js`：20/20。共通導線、出典アンカー、街・本文の表示順の回帰検査を追加。既存の天気、動画、保存、催し、GA4の検査も実行。
- GA4の変更ファイル許可リストは今回編集したファイルを個別に追加。計測項目、個人情報の扱い、保護された実行コードの検査は変更していない。
- 非公開の吉祥寺パルコ動画を再掲載していない。外部動画全件の再生確認は、この検証には含まない。

## 次に品質を上げる作業

1. 初見の読者に「吉祥寺の映像を探す」「週末の催しを探す」「記事から出典を確かめる」を試してもらい、迷った言葉と戻った箇所を記録する。今回の確認は編集者による点検であり、読者テストではない。
2. 作品紹介でも「どんな作品か→なぜこの街で紹介するか→何ができるか」を順に示す。全記事を同じ定型文にせず、具体的な場面を優先する。
3. 新しいコーナーを作る前に、既存4入口のどこに置くかを決める。主メニューに個々の企画を追加し続けない。
4. 街の記事を増やす際は、リードで問いと対象時期を示し、事実・見解・未確認を区別する。更新日は実際の更新時だけ変更する。
5. 読了率や訪問者数の改善は別途計測する。今回の編集で読者が迷わなくなったことや、月間10万人に達することはまだ実証していない。
