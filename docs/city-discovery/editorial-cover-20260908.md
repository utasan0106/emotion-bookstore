# 表紙再制作：作品が主役の文化雑誌

2026-09-08。ユーザーの再制作指示により、ec6dfb0 のキャラクター入り表紙と旧 cover-encounter 配布案は不採用。写真・公式導線・紹介フォームの修正は引き継ぐ。

## 目的と判断

帰宅後の数分、予定のない週末に「これを観たい・聴きたい」を見つける。先に都市を選ばせず、具体的な一作から始められる表紙にする。旧案は大きな架空の風景と一般的なコピーが実際の作品を押し下げていた。

視覚方針：白と黒、朱色のアクセント。実際の文化の写真、短い太い見出し、出典のある作品名、内容のわかる操作を近接させる。スマホでは写真→特集名→視聴入口を短くつなぎ、PCでは写真と本文を左右に配置する。説明本文16px以上、補助ラベル14px、写真注記12px。固定高で文字を切らない。自動送り・雨粒・架空キャラクターは使用しない。

初回特集は高円寺の踊り。既存の権利確認済み記録写真を使い、5分39秒の公式映像へ1クリックで進む。写真は現在の天候や開催状況を示すものではなく、記録写真であると短く記載する。書影や動画サムネイルを無断抽出しない。

## 原則を実装に置き換える

[NN/g：Visual Hierarchy](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/)と[Good Visual Design](https://www.nngroup.com/articles/good-visual-design/)を参照し、写真・主見出し・行動・補助情報の順に強弱を付ける。揃った列と余白で関連を示し、写真は内容の理解に役立つものを選ぶ。

[W3C：Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)を参照。読む横で自動的に動き続ける表紙を作らない。リンクの短いホバー・フォーカス表現だけに絞り、動きを減らす設定にも対応する。

確認基準：320/390/1280pxのレイアウト、写真欠落なし、横はみ出しなし、特集→公式映像1クリック、作品4入口、紹介フォーム、催し→公式1クリック、メニュー開閉とフォーカス、既存の端末内保存・計測・CSPを維持。静的検査の合格をデザインの良さの証明とは扱わず、画面を見て判断する。
