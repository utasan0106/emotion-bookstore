# 2026-09-09 文化導線の修正

## 実装

- 街別一覧の一律「この街を、もう少し深く」を撤去。音楽・本・映画からは同じ街の映像、映像からは場所・歴史へ接続し、進む理由を先に説明する。無関係な書籍を演奏の解説として扱わない。
- 既存の短編3本は削除されていなかった。トップ・街入口・街別カテゴリから一覧へ戻れる入口を復旧。新規作品や第三者プレイヤーは追加しない。
- motoki tanaka、吉田和史、仲野太賀の公式情報を短く要約。作品IDで対応づけ、同名別人の検索結果を混ぜない。年齢・受賞ランキング・出身地・街との居住関係は推定しない。出典と確認日を表示し、不明な人には欄自体を出さない。
- プロフィールは tools/artist-profiles.js。公式ページの写真・本文の長文転載なし。動画の再生成功は未確認。

## 次の開発順

1. 今回の導線修正をPreviewで確認。生成整合性、ローカルリンク、既存回帰を確認する。
2. 残る出演者も本人・所属先の一次情報で作品との同一性を確認できた場合のみ短い紹介を追加する。確認できない紹介文は埋めない。
3. 動画の再生・停止・選び直しと公式出口を実機で確認する。リンクの存在を再生・現地訪問の成功と扱わない。
4. 既存の文化探索を小規模検証する。新機能・街の追加・課金・募集連絡は今回実施しない。

保存、個人データ、解析、天気API、権利条件は今回変更しない。本番公開と全端末動作は、コード検証とは別に報告する。
