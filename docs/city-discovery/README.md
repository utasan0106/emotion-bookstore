# 街から作品へ：2026-09-08 の実装と編集方針

## 今回の判断

「このサイトで質のよい作品に出会い、必要ならその街に関係する外部特集で深める」を採用した。無関係なサイトのリンク集にはしない。HOMEにサイトの役割を明記し、街別の入口を一つ追加。街 → 音・映像／本・漫画／映画 → 作品の個別ページ、の順にページを遷移する。

最新のユーザー指示（各街に動画・本・映画を5〜10件程度）を、9月7日市場調査の「4街を均等拡充しない」より優先した。一方、比較体験の需要が未証明であるという市場調査の結論は変更しない。件数の増加を市場検証の成功と扱わない。

## 編集基準と外部特集

- 作品のタイトル・公開元・街との関係を、出版社、映画公式サイト、映画館の番組、公開者自身の映像説明などで確認する。一次ページの本文を取得できたものと、検索に収録された一次ページの説明だけを取得できたものが混在する。全件の全文読了や映像視聴済みとは報告しない。
- 本文や紹介文は短く独自に記述。書評・映画評の評価点や「高評価」「人気」の証拠を捏造しない。
- 「舞台」「撮影地」「上映企画」「会場の記録」を混ぜない。高円寺の映画祭に出た映画は、その街の撮影作品とは表示しない。
- PR映像・Web CMを実録取材と表示しない。古い映像を現在の生配信や開催中イベントと表示しない。
- 外部の主な行き先を、出版社、映画公式、上映特集、DVD案内など具体的に表示。映画鑑賞と作品データベースの閲覧を混同しない。
- 作品ページの主な出口は一つ。同一のURLを本文と出典で重複させない。動画のみ、サイト内のプレイヤーを開く操作と、表示できない場合に同じ動画へ移る外部リンクを別の機能として示す。
- 新潮社『1Q84』めぐりは「舞台かもしれない場所」。公園を確定ロケ地としない。

## 検証結果と限界

- 新規検証：60件、12の5件一覧、73ページのローカル参照、作品ページ内のURL重複なし、作品と外部動画IDの一致、画像と生成元の一致。
- 既存プレイヤーと新しい補助コードを同時実行した最小DOMテスト：本人操作だけの読込、iframe一つ、停止、再度開く、戻るキャッシュ、外部へ退出、CSPエラーの対象ホスト限定、共有ローダー欠落時の外部出口。
- 既存2体験：音楽25件・映画32件、配信CSP16件、計測482件、イベントの時刻表示、HOMEの文言・構造、作品の個別ページを確認。
- 追加カタログは既存の計測実験へ混ぜない。初回に解析・外部メディア接続を追加していない。YouTubeの読込を実再生、外部リンクのクリックを購入・現地訪問とは記録しない。
- **実ブラウザーでの新しいレイアウト・スマートフォン操作・20動画の実再生は未確認。** ローカルページへのブラウザー接続が `ERR_BLOCKED_BY_CLIENT` となったため、成功とは扱っていない。外部提供元の地域制限、削除、埋込制限、ログイン要否は実機確認が必要。
- 60件のうち外部の全文を取得できないものもある。参照先をソースに残したが、検索掲載の事実とその時点の提供継続は別。全ての動画IDを再生保証するものではない。

## 次の工程と投資判断

1. 新しいブランチをPreviewへ反映し、街一覧から映像を開く、停止して選び直す、本・映画の公式出口へ進む、の一連を実機確認する。問題のある項目は同じ街の確認済み項目へ差し替える。新規カタログの本番反映はまだ完了していない。
2. 最初に見える範囲で「何のサイトか」「何を観られるか」「外へ移るのか」を5秒程度で説明できるか観察する。ボタンの追加で説明不足を埋めない。
3. 掲載の偏りを調整する。神保町の動画は図書館の取材シリーズ、下北沢の3本は同一Web CMシリーズ、神保町の映画3本は溝口特集に寄っている。初回の幅としては成立するが、再訪の多様性は弱い。次は重複シリーズ枠から入れ替え、同じ件数内で人・街の時間・ジャンルを広げる。
4. 街が増えてもHOMEに全作品を積み上げない。追加は街ディレクトリー配下へ。各一覧を5〜10件以内に保ち、それを超える前に別テーマのページへ分ける。検索・ランキング・3Dは実際の探しにくさが確認されてから検討する。
5. 既存2体験の12人・14日比較検証を別枠で実施する。3人以上の自発再利用、4人以上の目的を持った公式行動、そのうち2人以上の観察外行動は投資判断の仮条件。需要の証明とは呼ばない。同素材のリンク集と同等なら専用UIへの追加投資を止める。

参加者募集・外部への連絡・課金・購入・出演者や権利者への連絡は実施していない。
