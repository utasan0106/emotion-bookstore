# 広告から見る吉祥寺：調査の試作

実装：`tools/city-research.js` に出典台帳・事実・解釈・未解決の問いを分離。
生成先：`/discover/essays/kichijoji-advertising.html`。
既存の吉祥寺コラムから導線を追加。既存映像は削除しない。

## 第2版：世代の視点と広告比較

- 出典は9資料。広告・販促の4事例と、2010〜2026年の8項目の年表を実装。
- パルコ2015、キラリナ2019春・秋、パルコ2021を区別。同じ施設の続報は独立標本にしない。
- アトレ沿革・2024改装発表、武蔵野市歴史年表・2026交通方針を追加。
- 「今30代」の高校時代を一律に固定しない。2000年代は未収集で、世代比較の完成ではない。
- 年表は出来事の整理、広告比較は発表内容の整理。来街効果・人口変化・個人の記憶の推定には用いない。
- 本人の私的記録を分析する機能は追加していない。

## 実物広告の表示方針

- 2021年吉祥寺パルコ公式発表に掲載された公式YouTube動画を、YouTube Privacy Enhanced Modeのプレイヤーで表示。
- 動画ID・発表元・確認日をデータ側で保持。実再生の可否はブラウザで未確認。
- 静止画はPR資料に掲載されていても、一般公開サイトへの転載許諾が明示されていない限り複製しない。
- 広告を本来の被写体として撮影した写真を「写り込み」として扱わない。
- 将来は権利者の書面許諾、明示ライセンス、または批評上の引用要件を個別に満たしたものだけを追加する。出典表示だけで適法になるとは扱わない。

## 初版の境界（履歴）

- 2資料の小規模試読版。広告史・年代別魅力調査を完成したとは扱わない。
- パルコ発表は広告主の意図の証拠であって、受け手の評価ではない。
- 2024調査は公表概要のみ。156,623端末を人数や回答総数へ読み替えない。
- 2021広告と2024調査の間に因果関係を置かない。
- 原画像、詩、インタビュー、広告コピーを転載しない。
- 現地訪問・当事者取材・動画再生確認は今回実施していない。

## 次のまとまり

1. 広告、沿線案内、来街調査、公開インタビューの候補30〜50資料を収集。公開日と対象時期を別々に保存。
2. 同一キャンペーンの転載を重複除去。広告主・媒体・場所・想定読者（明記がある場合のみ）・提案する行動・根拠を記録。
3. 年代比較は比較可能な資料が揃ってから。残存資料や媒体の偏りを開示。
4. 「映る場所／語られる過ごし方／語られないこと」の候補をAIで抽出し、原典に戻って一件ずつ照合。類似度を史実や因果関係に変換しない。
5. 確認した発見から読む・観る・訪れる導線へ接続。高円寺・下北沢・神保町へ展開。

公開前：生成整合、内部導線、モバイル表示を確認。本番公開状況と研究内容の完成度は別に報告する。
