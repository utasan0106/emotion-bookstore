## 長さ：1稿140字以内（URL込み）

**Xは文字数をそのまま数えない。** 日本語などは1文字を2、半角英数記号は1、
**URLは長さに関わらず一律23**として数え、合計280までを受け付ける。
日本語だけなら140字、URLを1本入れる稿は本文128字ほどが上限になる。

**URLが長いことを理由に本文を削る必要はない。** 短縮URLも要らない。
`?src=x` を付けても長さは変わらない。

書き換えたら必ず測る。目分量で判断しない。

```sh
node tools/check-post-length.js docs/city-discovery/LAUNCH-COPY-202610.md
```
