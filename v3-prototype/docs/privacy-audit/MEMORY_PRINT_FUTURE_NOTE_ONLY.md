# Memory Print — Future Note Only

Memory Print is not implemented or pre-authorized in the current V3 Release.

A future implementation must be a separate, explicit opt-in flow. Only after a
specific user action and future Product, Legal, Privacy, security, provider, and
payment approval may selected photo/text, shipping information, and payment or
order information be transmitted to named approved providers.

No current V3 data, consent, storage key, external action, or Privacy statement
authorizes that future transmission. Sprint05 adds no Memory Print code.
