## D-01 目黒サナダムシの Reveal に、宿主の事実を入れるか

**現状の Reveal**: 「1986年に駆虫。今も、その8.8mを標本で見られる。」

**問題**: payoff が弱い。「駆虫」は初見の参加者に通じない語で、
Hook（8.8mのサナダムシ。）との差分が「1986年」しかない。
本来いちばん効く事実は「それが実際に人の体から出てきたものである」こと。

**なぜ入れなかったか**: この Pilot が持っている verified note は
目黒寄生虫館公式による「8.8m標本の1986年駆虫・展示開始」までで、宿主は含まれない。
二次情報（Wikipedia / 一般記事）は「1986年8月、生鮮サケの生食で感染した男性から
初代館長が駆虫」としているが、公式一次情報で確認できていない。
本環境の egress proxy が `kiseichu.org` を遮断しており、確認手段がない。

**決めること**: 公式一次情報で宿主の記述を確認できたら Reveal に入れるか。
確認できない場合、二次情報を根拠に載せるか、載せずに済ませるか。
（Pilot の fail-closed 方針に従うなら「載せない」が既定。）

## D-02 ハチ公の Reveal と Hook の重複を詰めるか

**現状**: Hook「渋谷のハチ公、本物は上野。」/ Reveal「上野にいるのは、ハチ本人の剥製。」

**問題**: Reveal が Hook の「上野」を繰り返しており、増える情報が「剥製」の一語だけ。
いちばん効くのは「渋谷のあれは像で、上野のこれは体そのもの」という対比だが、
渋谷の銅像は現在の verified source（科博の展示DB）に含まれない。

**なぜ変えなかったか**: 対比を作るには科博以外の一次情報が要る。
また「剥製」を「体そのもの」と言い換えるのは、剥製の定義（毛皮を成形したもの）から
わずかに踏み込む。どちらも推定で埋めるべきではないと判断した。

**決めること**: 渋谷の銅像を別の一次情報で裏付けて対比を作るか、現状のままか。

## D-03 Human Test の参加者導線をどう用意するか

**現状**: 技術面の gate はすべて GO。外部参加者の募集・配布は未着手。

**なぜ進めなかったか**: 参加者募集に有償インセンティブやベンダー契約が要る場合、
支払い・契約は委任範囲外。

**決めること**: 12〜18名をどこから集めるか。無償・無契約で足りるか。

## D-04 Preview 配信面をどこにするか

**現状**: Production / main / Primary domain には触れていない。
参加者へ渡す URL は Preview 配信面を前提にしている。

**なぜ進めなかったか**: Production deploy と Primary domain 切替は禁止事項。
Preview deploy 自体は可逆だが、どの Preview URL を参加者に渡すかは
配布物の決定なので Founder 判断とした。

**決めること**: どの Preview URL で Cycle 01 を回すか。
