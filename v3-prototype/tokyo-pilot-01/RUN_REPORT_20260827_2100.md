## 3. UX 上、なぜ改善なのか

**Real Media が初めて Hook として機能する。** 原稿執筆カフェは縦位置のポスターを
横フレームに `cover` していたため、実測で card 46〜57% / 詳細 39〜53% しか
見えていなかった。円形ロゴも店名も切れており、Real Media が First Pull を
担えていなかった。目黒も横フレームに `contain` して灰色の中の細い帯になり、
8.8m という長さの証拠が読めなかった。いまはどちらも実寸比で全景が出る。

**payoff が一番大きい要素になった。** 詳細では既読の Hook が clamp(30〜50px)、
未知の Reveal が clamp(20〜28px) で、一番大きい要素が一番情報量の少ない要素だった。
Hook を小さい echo に降ろし、Reveal を見出しにした。

**2件目以降の Object Open が壊れていたのを直した。** dialog の scroll 位置が
Object をまたいで残っており、1件目を読んで閉じたあと2件目を開くと、実測で
m390 は scrollTop 232（Real Media の上端が -172）の位置から始まっていた。
Loop の中核である Object Open → Reveal が、2件目と3件目でだけ成立していなかった。

**読み上げ利用者にだけ答えが渡っていたのを止めた。** 一覧カードの `alt` が
「忠犬ハチ公の剥製」「サナダムシ標本」と Reveal の答えを名指ししていた。
画面上のテキストからは外していたのに、alt 経由で漏れていた。

**説明を読ませる段が3つから1つになった。** Object の手前に kicker / h1 / 特集チップの
3段があった。「それ、本当にあるの？」という評価は Object 自身が出すべきもので、
UI が先に宣言していた。いまは1行だけが Object の手前にある。

**First Pull が測定対象になった。** どの Object が1件目に来ても（abc / bac / cab）、
5つの viewport すべてで Real Media + Hook 全文 +「ひらく」がスクロールなしで
見えることを実測している。

**環境依存で入口が消えるのを直した。** ハイコントラストでは「ひらく」が背景を
失ってただの文字になり、Object を開く手がかりが無くなっていた。JS 無効時は
空の棚と「3つ、見終わりました。」だけが残っていた。

**古い情報や空の棚が参加者に届かなくなった。** 「外部サイクル前に必ず再確認」は
運用文でしか担保されていなかった。配信面の取りこぼしで Real Media が出ない
まま測ってしまう経路も塞いだ。
