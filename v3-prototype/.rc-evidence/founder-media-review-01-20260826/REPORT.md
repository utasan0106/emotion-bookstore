## 1. 結論（先に報告すべきこと）

**6 件すべてが MEDIA HOLD です。** 画面は完成していますが、
**Founder が「見たいか」を判定するための Real Media が 1 件も表示できていません。**

理由は本セッションの network egress 制限です。実測:

| host | 到達 |
| --- | --- |
| www.youtube.com / youtube.com | 不可（CONNECT 失敗） |
| www.youtube-nocookie.com | 不可 |
| i.ytimg.com | 不可 |
| publish.twitter.com / api.instagram.com / graph.facebook.com | 不可 |

したがって、

- **どの動画・投稿が実在するかを確認できない**（存在しない ID を書けば捏造になる）
- **埋め込みが許可されているかを oEmbed 等で確認できない**
- **仮に埋め込みコードを書いても、この環境のブラウザからは読み込めず screenshot に写らない**

指示の「埋め込み可否が確認できない場合は Media HOLD として表示せず、別対象へ勝手に置換しない」に従い、
**6 件すべてを HOLD**とし、対象の差し替えは行っていません。

## 4. Preview で embed を見るための追加の障害（重要）

仮に embed 可否が確認できても、**現在の CSP では Preview 上で iframe が表示できません**。

- `vercel.json` の `/(.*)` ルールが `frame-src 'none'` を課しており、V3 配下の全パスに適用されます。
- youtube-nocookie を許可する CSP P0 の変更は**別 branch で凍結中**で、本 branch には含まれていません。

したがって Preview で実際に動画を見るには、**CSP P0 の解凍 or 本用途向けの限定的な frame-src 許可**が必要です。
本タスクの scope 外のため**私の判断では変更していません**。
