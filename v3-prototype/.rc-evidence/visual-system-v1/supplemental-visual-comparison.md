## Authority boundary

The reference images were used only for visual polish: Navy/Aqua/White balance, spacing,
hierarchy, density, photographic treatment, button levels, shadow, typography, and
cross-viewport finish. Exploratory copy, shelf names, navigation, and example content in
the mockups were not copied. Current Product/UX Canonical remains authoritative.

## Six-reference review

1. Moodboard: white-dominant editorial composition, natural restrained photography,
   geometric Aqua/Navy overlays, and serif-only heading emphasis are present.
2. Button hierarchy: Navy filled primary, white/Navy outline secondary, compact utility,
   and coral reversible saved state are consistently separated.
3. Shadow/elevation: cards use restrained `0 4px 16px rgba(23, 50, 77, .06)` separation;
   buttons remain flat and overlays alone receive modal elevation.
4. Mobile navigation: small header mark plus MENU and persistent Home / 保存済み / メニュー
   bottom navigation are present; `選ばずに見る` remains reachable from MENU.
5. Navy + Aqua + White: Navy anchors actions and navigation, Aqua is a sparse signal/accent,
   and white remains the dominant page surface.
6. Desktop hero/density: Entrance uses a medium-height photo-led split composition with
   visible continuation; discovery uses readable three-column rhythm at 1200 and four at
   1440 where the content structure supports it.
