# 感情書店：入口の方向比較

対話で確認した目的：暇だな→何かないかな→こんなのあるんだ→見てみよう・行ってみよう。何のサイトかすぐ分かり、カテゴリで整理され、短い時間にも楽しみがある。

A：写真と作品を見渡せる入口。B：約30秒の小文を入口にする構成。書き下ろしの小文は両案ともその場で開けます。映像は長さを明示して公式へつなぎます。阿波おどりはサイト全体の看板にせず、一つの映像として掲載。

index.htmlで比較、a.htmlとb.htmlで各案を開けます。リンク先は既存サイトです。展示・ライブのカテゴリはこのラフでは共通の催し一覧へつながります。専用カテゴリ絞り込みと最終掲載作品は、方向決定後に詰める対象です。

写真は既存の出典確認済み素材によるイメージ。実際の作品カバー・演奏写真ではありません。小文は作品本文の引用ではなく今回のオリジナル原稿案。約30秒は目安です。ライセンスと出典を同梱。

今回の成果物は比較用ラフです。公開サイトは変更していません。デザインの承認・本番完成を意味しません。390pxの比較画面で目視確認し、両案の読み物を開く操作を確認しました。
