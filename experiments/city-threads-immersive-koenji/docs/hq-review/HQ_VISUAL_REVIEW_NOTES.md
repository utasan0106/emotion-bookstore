## 1. First 5 seconds で利用者に見てほしいもの（A）
暗い面に、現在の高円寺の写真が一枚だけ浮いていること。写真の右下の縁から Ivory の紙の角が覗き、そこに「1957」とあること。文字は「高円寺」「2026」と一行のヒントだけ。触るべき場所が「写真の角」の一点に絞られているか。

## 2. First Pull で何が変わるか（B → C → D、`HQ_FIRST_PULL_SEQUENCE/`）
角に触れると、写真は動かず、下に「阿波おどり ｜ 1957 ── 2026 ｜ 5つの節目」が開く（B）。縦に進むと、現在の写真が奥へ沈んで暗くなり、1957 の紙が手前側から少し大きく・薄く現れ、読む距離に落ち着く（C→D）。錨の年は 2026 から 1957 へ転がる。「ページを下へ読んだ」ではなく「時間を戻った」に見えるか。

## 3. 1957 到達時に何を理解してほしいか（D、L）
紙の年「1957」と「『ばか踊り』として始まる」が先に読め、その下の本文で「最初から阿波おどりではなかった」「商店街の青年部の記念行事」が分かること。紙の中央の「編集部の余白」（1票差の話）が、資料ではなく編集の声として区別されているか。

## 4. Layer persistence で何を感じてほしいか（E、F、M）
1960年代に着いたとき、1957 の紙と 2026 の写真が奥に薄く残って見えること。層が入れ替わるのではなく、積み重なっていく感覚。奥の層が邪魔に見えるか、記憶として見えるか。

## 5. Evidence Open で何を理解してほしいか（G → H、N）
「この資料に近づく」で、暗い面の中の紙が手前へ寄り、他の層が沈み、紙色の面に 資料名・年代・Source・URL・この資料から確認できること が出ること。ページ遷移ではなく「近づいた」と感じるか。閉じると元の位置と焦点に戻る。

## 6. Ending で何を感じてほしいか（I、J、O）
最後に、はじめと同じ現在の写真が戻り、その奥に歩いてきた紙（2025・1976・1960年代・1957）が透けて重なっていること。同じ写真が最初と違って見えるか。出口は「行く／観る・読む／公式情報」の3群だけで、「この先は、高円寺にある。」で終わる。

## 7. Mobile と Desktop の意図的な差
- Mobile：層は画面上部の中央（幅 60vw）、本文はその下に一列。本文の背後に静かな暗い面を敷き、移動中に層と文字が重なっても読める。奥行きは Desktop の 0.7 倍。
- Desktop：層は左 32% に、本文は右の読む列。奥行きはそのまま。Desktop にだけ存在する意味は作っていない（Mobile に無い Core Meaning なし）。

## 8. Claude 自身が Visual 上まだ弱いと考える点
- 紙の層が「活字だけの紙」で、資料の物質感（印刷・紙端・写真）がない。権利未確定のため意図的だが、North Star の「実在資料が主役」には届いていない。
- 現在の写真は Wikimedia Commons の一枚（夜の路地）で、演舞場や商店街の昼の表情ではない。Entrance の第一印象を「夜の高円寺」に固定している。
- 奥に沈んだ層の重なり（横ずれ 2.2%・縦ずれ 1.6%）が控えめで、Mobile では「積み重なり」が伝わりにくい可能性がある。
- 資料に近づいたときの dialog が紙色の面として前に出るため、「層に近づく」より「モーダルが開く」に見える可能性がある。
- 証跡はこの環境のフォント（ゴシック）で描画されている。明朝の実機表示は未確認。
- 1976 の紙のラベル「連が出揃い、海を渡る」と本文の「海を渡る」が重複気味。

## 9. North Star に対して未達かもしれない点
- 2-1「実在する街の写真・古い写真・ポスター・地図・新聞・活字・光・影・紙やフィルムの質感」のうち、実装できたのは 現在の写真・活字・光・影・紙（CSS）だけ。古い写真・ポスター・地図・新聞は Rights 未確定で不在。
- 2-3「現在の街が奥へ沈む → 古い写真・地図・資料が別の depth から現れる」の「古い写真・地図」が活字の紙に置き換わっている。
- 2-5「その資料へ少し近づく感覚」は、層の接近（+140px）と dialog の組み合わせで表現しているが、カメラ移動は使っていない。近づく感覚が弱ければ、層の接近量と dialog の出方は要再検討。
- 3「高円寺阿波おどりって、こう始まったんだ」は本文で伝えているが、視覚（紙の中の文）だけで伝わるかは Human Review 待ち。
