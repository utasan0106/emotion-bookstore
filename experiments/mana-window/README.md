# まな：実写とアニメの合成試案

2026-09-08。非公開の独立試作。本番反映はしていません。

## 開くページ

フォルダ全体を展開し `composite.html` を開きます。アカウント、ビルド、APIキーは不要です。

- 神保町の写真にまなを追加した静止画を表示します。
- 「元の写真を見る」で合成前と比較し、同じボタンで試案へ戻れます。
- 静止画の合成確認です。ライブ・歩行・まばたきの完成品ではありません。
- 合成元の写真と著作者・ライセンス、AIで加えた変更は画面末尾に記載しています。

`index.html` は4街の写真と作品への接続を試す別ページです。最終的なライブ内合成を実装したものではありません。旧デザインの三面図と画像全体の呼吸効果は削除しました。

## 最新の方向

背景は実写、まなはアニメの線と色を保ちます。足の接地、同じ光の方向、実際の物との前後関係で同じ空間に見せます。顔と服は試案であり、採用承認済みではありません。

`live-action-direction-20260908.md` が同梱されていれば最新方針です。リポジトリでは `../../docs/mana/live-action-direction-20260908.md` にあります。

## 現状と次工程

2D原画とパーツを整え、表情・歩行ポーズ、前景マスクと影を作り、固定した実写映像で6〜8秒の動作を確認する順序です。現行ライブの採用条件を満たして確認済みの映像は0件。録画・写真をライブと表示しません。

リポジトリの `production` にあるBlenderのシーン準備コードは補助研究資料で、今回の確認用ZIPには同梱しません。入力仕様とPython構文は確認済みですが、Blender本体で未実行です。立体・リグ・レンダリング・歩行が完成したものではありません。

画像はAI生成の候補画で、編集可能な2Dパーツ原本ではありません。キャラクターの本人らしさや静止画一枚だけで、連続した動作の品質を保証しません。

## 実装

初回の外部API・解析・動画接続を追加しません。写真と生成画像はローカルです。作品リンクを選ぶと感情書店の公開サイトへ移動します。非公開・終了動画は掲載しない方針を継続します。

`review.html` は合成試案と4街の導線を320/390/768/1280pxで確認するための補助ファイルです。生成画像は比較画面で縮小表示するため、元画像の表示と細部が異なる場合があります。
