# まなの立体制作：作業手順と受入条件

2026-09-08。対象は感情書店の案内役。**制作準備ファイルであり、完成した3Dキャラクターではありません。**

`prepare_mana_scene.py` と `scene-spec.json` は、新しいBlenderシーンに、基準画・関節位置のガイド・確認カメラ5個・エリアライト3個を配置するためのコードです。
今回の環境にはBlender本体がなく、Python構文と設定データだけを検証しています。`.blend`・リグ付きメッシュ・最終レンダーは未生成です。

## 再現する作業環境

Blender 4.5 LTSを想定して準備。最新版追従より同じ環境で再現できることを優先します。採用前に実機で動作を確認して使用版を固定します。[Blender公式の4.5 LTS案内](https://www.blender.org/download/releases/4-5/)
Autodeskの参照記事は造形・変形・演出の原則に使い、3ds Max 2017固有のコマンドや有料プラグインを前提にしません。

Blenderを使える環境では、展開したフォルダの `production` から次を実行します。既存の作業を開いたままではなく、別プロセスで実行する手順です。

```bash
blender --background --factory-startup --python prepare_mana_scene.py -- --lighting studio --output ./output/mana-studio.blend
blender --background --factory-startup --python prepare_mana_scene.py -- --lighting evening --output ./output/mana-evening.blend
```

出力先に同名ファイルがあれば停止します。旧シーンや素材の削除、ダウンロード、外部送信は行いません。
構文・データだけを検査する場合：`python3 prepare_mana_scene.py --validate-only`。

## 1. モデリング：目標の大きさで形を決める

最初にWeb上の表示を想定した全身約240pxと、顔のアップの両方で評価します。輪郭、目の間隔、首と肩、前腕と上腕、手の大きさを先に決めます。
正面だけを合わせず、正面・斜め・側面・背面の確認カメラを使います。生成基準画は厳密な三面図ではないため、左右や衣服の不一致はモデル側で統一します。
髪は大きな束で輪郭を作り、細い毛の追加は最後。眼鏡とポケットの本は、変形させる体・衣服から分けます。
顔と関節付近は変形に沿う面の流れを作り、不要な頂点・重複面・異常な法線を整理してからリグへ渡します。[顔の造形と面構成](https://area.autodesk.jp/column/tutorial/character_arpeggio/01_modeling/)、[情報量と多方向の確認](https://area.autodesk.jp/column/tutorial/celllook-character-modeling/01-basics-preparation/)

完了条件：正面・45度・横の顔の印象が一致する／靴を含めた接地が揃う／肩・肘・膝の曲げ試験に必要な面がある。

## 2. リギング：まず小さく、変形を確認できる状態に

骨組みガイドはメートル単位、高さ1.6mを作業上の仮尺度にしています。人物プロフィールとして身長を公表する意味ではありません。
実際のモデルに合わせて肩・肘・股関節・膝・足首を調整してから、変形用ボーンに変更します。ガイドの座標にメッシュを無理に押し込みません。
制作リグの操作用ボーンとWebへ出す変形用ボーンを分けます。足は接地を制御しやすいIK、腕は振りに使うFKと本を持つための固定を用途で選びます。最初から万能な仕組みにしません。
自動ウェイトは初期値としてのみ使用。肩上げ、肘曲げ、膝曲げ、しゃがみの確認姿勢を用意して手で直します。眼鏡や本は体のように歪ませません。[人体の構造とスキニング](https://area.autodesk.jp/column/tutorial/character_arpeggio/06_rigging_01/)

完了条件：足が地面に固定できる／肘・膝の向きが反転しない／肩や袖が潰れない／服に足が突き抜けない。

## 3. 表情：気持ちを押しつけない、小さな変化

初期は左右のまばたき、視線、口角だけ。目を閉じるときに、上まぶた・下まぶた・まつ毛・眼球の関係を確認します。
「喜び」「悲しみ」の完成顔を大量に作る前に、左右の目や口角といった部位単位の変形を作り、組み合わせても顔が崩れないかを確かめます。[フェイシャルとモーフの分割](https://area.autodesk.jp/column/tutorial/character_arpeggio/07_rigging_02/)
まなは利用者の文章を分析して表情を変えません。定型の案内と、明示的な操作にだけ反応します。

完了条件：正面・斜めでまばたきに穴や食い込みがない／眼鏡越しに視線がわかる／平常時の顔と別人にならない。

## 4. アニメーション：8秒の一つの場面を完成させる

原案は「一枚のしおり」。本を閉じてしおりを挟む→気配に目を向ける→頭・胸の順で窓を向く→落ち着いて止まる。
24fps、192フレームを作業範囲にしています。全キーを滑らかにする前に、意味が伝わる4〜6個の主要な姿勢を作ります。
腰・胸・頭の動きが読めてから、手、目線、まばたき、髪や裾の遅れを追加します。作業中は重い髪や装飾を簡略化して、タイミングを優先します。[簡易リグとキーポーズ](https://area.autodesk.jp/column/tutorial/character_arpeggio/08_animation/)

歩行は別クリップ。左右の接地、沈み、通過、上がりを揃えてから前進を合わせます。接地中の足が滑る素材を「歩行完成」としません。ループ端の姿勢・速度も確認します。
生成動画を使う場合も、正面画だけから長い動画を量産せず、短い固定カットで同一性を確認してからカットを増やします。静止画の拡大縮小とキャラクターの身体運動は区別します。

## 5. ライティング：顔・衣装・場所を同時に読める光

用意した2プリセットは比較の出発点です。studioは暖かい主光＋弱い寒色の補助光、eveningは暖かい近くの明かり＋青い環境光を想定。
光量・大きさ・位置を同時に変えず、主光だけ→補助→輪郭の光の順に足します。暗部を黒く潰して雰囲気を作ることは避け、顔と眼鏡の反射を確認します。
エリアライトのサイズは影の柔らかさに関係します。光の正規化や単位はレンダラーごとに確認し、Arnoldの数値をBlenderにそのまま移しません。[Arnold公式：ライト](https://help.autodesk.com/view/ARNOL/ENU/?guid=arnold_user_guide_ac_lights_html)
露出と色管理を固定した比較画像を残し、背景写真との明るさ・光の方向・接地影を合わせます。今回の設定値は撮影現場の測定値ではありません。

完了条件：昼・夕方の両方で肌・髪・衣装が判別できる／眼鏡の反射が目を隠さない／動画で影やハイライトがちらつかない。

## 6. 書き出しとWebでの確認

本制作データは`.blend`、表示用候補は骨格・表情・アニメーションを保持するGLB。制御用の制約は必要に応じて変形ボーンへベイクします。
骨格と頂点ウェイト、モーフの重みのアニメーションを、書き出したファイルを読み戻して確認します。[Khronos：Skinning](https://github.khronos.org/glTF-Tutorials/gltfTutorial/gltfTutorial_019_SimpleSkin.html)、[Morph Targets](https://github.khronos.org/glTF-Tutorials/gltfTutorial/gltfTutorial_018_MorphTargets.html)
Web版と高品質な動画用レンダーは別に管理。髪一本ずつの計算や高解像度素材を、そのままスマートフォンへ送らない構成にします。
初期予算は18k三角形以内、1Kテクスチャ2セット以内、5MB以内。実測した転送量・描画時間を見て調整する目標であり、性能保証ではありません。

最初は利用者操作で表示。停止・閉じるを常設し、動きを減らす端末設定とタブ非表示に追従します。まなを閉じても作品を観る操作が失われないことを検証します。

## 7. 公開前の判定

| 検査 | 直すべき症状 | 合格前の扱い |
|---|---|---|
| 造形 | 横顔の別人化、眼鏡や衣装の不連続 | 基準画に戻って修正 |
| 変形 | 膝や肘の潰れ、袖・裾の貫通 | ウェイト・補正形状を直す |
| 動き | 足滑り、重心の不自然さ、指の破綻 | 短いカットに絞って修正 |
| 透過 | 市松模様が画像に焼き付いている | 透過素材として使用しない |
| 光 | 目が反射で見えない、暗部潰れ、ちらつき | 光源を分けて原因を確認 |
| Web | 操作を覆う、停止できない、体験を待たせる | 本番に入れない |
| 映像 | 配信終了、非公開、所在地不一致 | ライブ一覧から外す |
